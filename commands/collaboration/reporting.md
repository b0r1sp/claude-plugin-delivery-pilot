# /reporting — Create Report

Create a structured report for internal or external recipients.

If `$ARGUMENTS` is provided, treat it as the report type or audience (e.g. "Weekly", "Monthly", "Management").

## Report Types
- **Weekly**: Short week-in-review (1 page)
- **Monthly**: Detailed progress report
- **Executive Summary**: Compact decision brief
