# /escalate — Escalation

Formulate a clear, factual escalation message.

If `$ARGUMENTS` is provided, treat it as the topic or recipient.

## Principles
- Facts over emotions
- Clearly separate problem, impact, and required action
- Provide solution options, not just the escalation
- State urgency clearly

## Output Format

**Escalation – [Date]**  
**Topic:** $ARGUMENTS  
**Urgency:** High / Medium

---

**Situation:**  
[What happened? Facts, data, timeline]

**Impact:**  
[What happens if no action is taken? Cost, risk, delay]

**Actions taken so far:**  
- 

**Decision / Support requested:**  
- [ ] Option A: 
- [ ] Option B: 

**Decision deadline:** 

---

Ask for situation, impact, and requested support before finalizing.
