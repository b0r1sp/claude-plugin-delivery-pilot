# /update — Stakeholder Update

Create a concise stakeholder update.

If `$ARGUMENTS` is provided, treat it as the project or target audience (e.g. "Management", "Client").

## Tone
- Professional, direct, no padding
- Positives first, then risks/blockers communicated transparently
- Clear call-to-action at the end

## Output Format

**Project Update – [Date]**  
**To:** $ARGUMENTS  
**From:** Delivery Lead

---

**Overall Status:** 🟢 On Track / 🟡 At Risk / 🔴 Off Track

**Highlights this week:**
- 

**Risks & Mitigations:**
- 

**Next Steps:**
- 

**Decisions needed:**
- [ ] 

---

Ask for project status, highlights, and open points if not available in context.
